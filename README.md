# WP Varejo Digital

Site estático para GitHub Pages.

## Estrutura
- `index.html` — página principal
- `styles.css` — visual e responsividade
- `main.js` — interações do diagnóstico
- `solucoes/` — páginas individuais das soluções
- `politica-de-privacidade.html`
- `assets/logo.svg`
- `.github/workflows/main.yml` — publicação no GitHub Pages

## Publicação
No GitHub, deixe o repositório público se sua conta não tiver acesso ao Pages privado.
Em Settings > Pages, escolha **GitHub Actions**.
